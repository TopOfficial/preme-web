# ECI visual system

## Direction
A concise industrial catalogue with a navy editorial panel, large real domain photography, open white content areas and restrained red navigation accents. The red ECI logo remains unmodified. English distributor language takes precedence over broad marketing claims.

## Typography and colour
Locally hosted Barlow in regular, medium and semibold. Body 17px/1.55. Responsive display headings 42–74px, section headings 30–43px. Dark navy #0e2b46, text #112e4a, white #ffffff, pale blue #eef3f6, accent red #ce2432. Secondary copy #506375. No gradients, decorative metrics or graphic ornaments.

## Layout
Maximum content width 1320px, desktop gutters 56px, mobile gutters 20px. Home opens with a 46/54 split between copy and photograph. Five image-led domain links form the catalogue entry. Solutions overview uses a two-column text layout and a four-item service row. Footer repeats direct contact information.

## Catalogue and navigation
Four top links: About, Products, Solutions, Contacts. Product areas are ordinary navigable links, not client-only tabs. Breadcrumbs preserve the domain/category hierarchy. Product listings have rectangular illustrations, names, summaries and explicit placeholder labels. Details use a two-column image/overview layout. Mobile navigation toggles an expanded list below the header.

## Responsive and interaction behaviour
At 760px the hero, content sections and detail layouts stack; domains and product cards use two columns. Product area navigation scrolls horizontally. Images zoom subtly on hover; red arrows indicate navigation. Reduced-motion users receive no transitions. Focus outlines use the red accent. A skip link targets the main content.

## Content integrity
Original product illustrations are clearly sample content. Sourced domain photographs have visible representative-use notes. No invented models, performance specifications, manufacturers, availability or credentials. Enquiries use email links; no message-submission success state is shown.

## Verification limits
Authored source reviewed, TypeScript and lint checked, production build validated and all 21 reachable pages plus 5 invalid paths checked via HTTP. Browser screenshot or interaction QA was not requested and was not performed. Impeccable context and concept launcher failed without diagnostics; written guidance was applied directly.

## Navigation reliability update
All page links use the native `SiteLink` anchor component. The initial deployed Vinext Link prevented normal navigation then threw in its client navigation runtime; native document navigation preserves browser history, keyboard actions and open-in-new-tab behaviour. User approved the existing design; its visual system remains unchanged. Product areas now include Software and Search and Rescue in place of Security.
